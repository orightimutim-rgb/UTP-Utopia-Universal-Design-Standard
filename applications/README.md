# 🛠️ 應用實踐

本目錄展示如何將 UTP 的倡議轉化為實際的工具、應用和協作方式。

這些應用可能使用不同的技術棧、不同的平台，但都遵循 UTP 的核心原則：
- ✅ **通用設計** — 考慮各種神經多樣性和生理差異
- ✅ **平權精神** — 不製造新的數位落差
- ✅ **開放協作** — 歡迎各種形式的參與
