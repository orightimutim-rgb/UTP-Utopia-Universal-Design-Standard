# Google Keep 暫存匣（給 Cursor / GPT 讀）

> 用途：你從 Keep **手動貼上**的筆記暫存處。Agent **無法**直接連 Google Keep。  
> 協定見 [`../KEEP_GPT_SYNC.md`](../KEEP_GPT_SYNC.md)。

## 使用方式

1. 在 Keep 選好要同步的筆記  
2. 複製全文，貼到下方「Inbox」區（新的放最上面）  
3. 告訴 Cursor 或 ChatGPT：「讀 `docs/learning/keep-inbox.md`」  
4. 處理完把該則移到「已處理」或刪除敏感內容
