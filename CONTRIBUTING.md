# Contributing

This repository is part of the UTP Utopia Universal Design Standard project.

The current tree includes a SwiftUI iOS client for Cursor Cloud Agents. Keep changes small, reviewable, and reversible.

## How to contribute

1. Open a focused pull request from a new branch.
2. Prefer documentation or one-file fixes unless the task needs more.
3. Do not commit API keys, tokens, certificates, or other secrets.
4. Describe the change in a short summary and include a test plan.

Application folders under `applications/` should include a `README.md` that explains how the work serves universal design.

For agent-operated work, see [AGENTS.md](AGENTS.md).
